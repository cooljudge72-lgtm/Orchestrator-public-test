# T-002: Arabic Judicial Text Metadata Extractor

## Goal
Build the first local Python component of the judicial assistant. Extract structured metadata from synthetic Arabic judicial text without using any cloud services.

## Scope
- Python standard library only.
- No network access, external APIs, OCR, or AI models.
- Use synthetic Arabic examples only; never real case files or party identities.
- Do not access private or judicial repositories.

## Function
Implement `extract_case_metadata(text: str) -> dict`.

Return a dictionary containing:
- `case_number`: case number as a string, or None.
- `case_year`: four-digit year as a string, or None.
- `judgment_date`: date in YYYY-MM-DD format, or None.

Recognize examples such as:
- `الدعوى رقم ١٢٣ لسنة ٢٠٢٤`
- `الاستئناف رقم 456 لسنة 2025`
- `صدر الحكم بتاريخ ١٥/٠٣/٢٠٢٥`

## Acceptance Criteria
1. Support Arabic-Indic and Western digits.
2. Recognize case numbers following `الدعوى رقم` or `الاستئناف رقم`.
3. Normalize extracted digits to Western digits in the returned data.
4. Convert valid DD/MM/YYYY dates to ISO YYYY-MM-DD.
5. Return None for missing or invalid fields; never invent missing information.
6. Reject non-string input with ValueError.
7. Provide at least 10 unit tests using synthetic Arabic text.
8. Keep all processing local and deterministic.
9. Do not modify T-001 or existing workflows, rulesets, permissions, or repositories.
