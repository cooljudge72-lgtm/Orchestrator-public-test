# T-001: `celsius_to_fahrenheit` (synthetic pilot task)

Machine-readable limits are in `tasks/T-001.json` (read by the status check from `main` only).

## Goal

Add `pilot/temperature.py` with `celsius_to_fahrenheit(value) -> Decimal`.

## Acceptance criteria

- Accepts `int`, `float`, `Decimal` and numeric `str`; returns a `Decimal` rounded to 2 decimal
  places (`ROUND_HALF_EVEN`). `F = C * 9 / 5 + 32`, computed in `Decimal`.
- Raises `ValueError` for: `bool`, `NaN`, `Infinity`/`-Infinity`, non-numeric values, and values
  below absolute zero (`-273.15` °C).
- At least 6 unit tests in `tests/test_temperature.py` covering conversions, rounding and each
  rejection. Python standard library only.
- Only the files listed in `allowed_paths` may change. Synthetic data only.
